### 绘图统计

插件会在每次成功生成图片后记录统计数据，批量生成按实际图片张数计数；失败请求不会计入统计。统计数据保存在用户数据文件中，并兼容已有的额度数据。

绘图统计按**北京时间每天 05:00** 分界，凌晨 00:00 至 04:59 的出图
归入前一个统计日；不改变签到和额度规则。

查看当前统计日的总张数和成功出图排行榜（前十名）：

```
nai今日排行
```

查看当前统计日及前六个统计日的总张数、逐日张数和用户排行：

```
nai七日统计
```

七日统计不是自然周，也不是精确滚动 168 小时，包含当前尚未结束的统计日；
每日明细中的日期表示该日 05:00 至次日 05:00，命令会显示具体周期。
总张数包含所有用户，不仅是排行榜前十名。

查看插件累计成功生成的图片总数：

```
nai总数
```

排行榜按对应周期的出图数量降序排列；未设置昵称时只显示用户 ID 的后四位。
升级时会先核对逐条成功审计并备份旧用户文件，再重算历史每日统计。
如果审计不完整则拒绝迁移，保留原文件；累计数量、额度、名单及签到日期不会被重算。

## 📊 队列系统

当多个用户同时请求画图时，系统会自动进行排队管理。

### 查询队列状态
```
nai队列
```

显示当前正在处理的请求数、排队等待的请求数，以及队列是否已满。

> 💡 当队列已满时，新的画图请求会被暂时拒绝，请稍后重试。

---



### Anlas 账户与消耗审计

管理员命令：

```
nai账户
nai审计
```

`nai账户` 查询已配置 Token 的订阅状态和 Anlas 余额；`nai审计` 查看本地记录的最近生成、账号、参数及生成前后余额变化。审计文件保存在插件数据目录的 `anlas_audit.jsonl` 中。
