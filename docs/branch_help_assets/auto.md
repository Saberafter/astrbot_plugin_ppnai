# 泡泡画图 · 自动画图

返回总览：`/nai`

> 当前部署的自动画图启用命令已禁用，以下保留完整功能说明。查看本帮助不会修改配置或开启自动出图。

### 自动画图

监听主 AI 回复，自动生成配图。

#### 查看状态
```
nai自动画图
```

#### 开启自动画图
```
nai自动画图开
s=预设名
s2=预设名
cs1=角色名
cs2=另一个角色名
```

#### 关闭自动画图
```
nai自动画图关
```

> ⚠️ 自动画图的额度由开启者承担

#### 在自动画图里使用 `nai` 参数个性化

`nai自动画图` 的预设内容支持写入与 `nai` 相同的 `key=value` 参数（例如 `model/size/steps/seed/role/i2i/vibe_transfer/character_keep/前置正向...`），用于个性化控制自动出图风格与参数。
