# 泡泡画图 · 功能导航

输入下面的命令查看对应功能，不会触发绘图，也不会消耗 Anlas。

### /nai 画图

直接填写 Tag，或用 AI 把自然语言转成提示词；批量生成与参数覆盖。

### /nai 参数

正反向词、模型、尺寸、步数、种子、采样器及多角色定位。

### /nai 预设

保存并复用画质、角色、场景和参数组合；查看、修改与删除。

### /nai 角色

角色 Tag 库（CS）：用角色名复用固定 Tag，不让 AI 重写。

### /nai 识图

AI 识图、图生图、画风参考与角色保持；各自的区别和用法。

### /nai 自动画图

根据聊天回复自动配图的用法；当前未启用，不会因查帮助开启。

### /nai 图库

保存参考图片，后续用图库名称引用；原图与预览图管理。

### /nai 额度

签到、额度、出图排行、排队；管理员账户余额和消耗审计。

### /nai 输出

原图、参数记录、二维码、网盘链接、出图短评及缓存设置。

### /nai 帷幕

设置、查看与撤下当前会话的幻影坦克表图。

### /nai 管理

黑白名单、用户额度及管理员命令。

## 快速画一张

```
/nai
tag=1girl, coffee shop, smile
```

绘图参数与分支名分开使用。完整参数用 `/nai 参数` 查看。

自动画图当前未启用；管理和账户命令仍受原有权限限制。
