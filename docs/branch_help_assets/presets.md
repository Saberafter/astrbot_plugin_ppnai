# 泡泡画图 · 预设

返回总览：`/nai`

> 预设像可复用的缩略词：先保存，再通过 `s1=预设名` 引用；原始 Tag 不会在基础 nai 模式被 AI 改写。

预设正文可以整段粘贴、自由换行，无需逐行 `tag=`。旧写法无需迁移。`s=预设名` 可以放在正文开头、中间或末尾，不切换当前提示词分区。

普通参数优先级：直接填写 > s1 > s2。正负与前后包装继续累加；同编号角色按完整条目覆盖，避免混合不同预设的人物特征。预设分区独立解析，不随引用位置绑定到当前角色。

## 📝 预设管理

预设用于保存一组可重复使用的提示词和绘图参数。预设创建后不会自动应用，需要在 `nai`、`nai画图` 或 `nai自动画图` 中通过 `s=预设名`、`s1=预设名` 等方式引用。

#### 使用预设 `s1`、`s2`

预设是预先保存的提示词和参数集合。基础命令 `nai` 会直接读取并合并预设内容，不会调用 AI 重新理解或改写预设，适合需要固定提示词和固定参数的场景。

只使用一个预设：
```
nai
s1=预设名
```

同时使用多个预设时，按编号填写：
```
nai
s1=画质
s2=角色
s3=场景
```

- `s1`、`s2`、`s3` 等表示预设的合并顺序，编号越小优先级越高。
- 同一编号不要重复填写；需要叠加内容时使用不同编号。
- 也可以混合预设和手写参数，手写参数会覆盖同名的预设参数：
```
nai
s1=画质
s2=角色
tag=1girl, reading a book
steps=28
```

在 `nai画图` 中也可以使用预设：
```
nai画图
s1=画质
s2=角色
ds=坐在窗边看书
```

这里的 `s1`、`s2` 仍会按顺序合并，但因为 `nai画图` 是 AI 辅助模式，合并后的预设内容和 `ds` 会一起交给高级参数 LLM 转换为最终绘图参数；只有基础命令 `nai` 才是完全不经过 AI 改写的预设处理。

### 查看预设列表

查看自己可用的预设：
```
nai预设列表
```

资源管理员可以查看并使用全部预设；如果开启了 `general.list_all_resources`，普通用户也可以查看并在绘图中使用全部用户的预设、图片图库和角色 Tag 库资源，列表会按所有者分组显示。关闭时，普通用户只能查看和使用自己的资源，但系统资源及管理员配置的默认预设仍可用。

### 查看预设内容

```
nai预设查看 预设名
```

会显示预设的完整内容和预览图。不填写名称时等同于查看预设列表。

### 添加预设

添加预设时，标题和内容必须分行填写：
```
nai预设添加 预设名
这里是预设内容
tag=1girl, cute
negative=bad quality
size=竖图
```

第一行是预设名称，第二行开始是预设内容。内容可以写普通提示词，也可以写多个 `key=value` 参数，例如 `tag`、`negative`、`model`、`size`、`steps`、`seed` 等。

例如固定保存一个角色和画质预设：
```
nai预设添加 白发少女
tag=1girl, white hair, blue eyes
negative=bad anatomy, low quality
model=nai-diffusion-4-5-curated
size=竖图
steps=28
```

添加成功后可以这样使用：
```
nai
s1=白发少女
```

添加预设时，如果同一条消息附带图片，第一张图片会保存为预设的预览图。预设内容本身不会调用 AI，保存什么内容就保留什么内容。

### 修改预设

管理员或预设资源所有者可以修改预设：
```
nai预设修改 预设名
这里是新的预设内容
tag=1girl, updated content
steps=28
```

修改时也可以在同一条消息中附带图片，第一张图片会更新预览图；不附带图片则只修改文字内容。

### 删除预设

资源管理员可以删除任意预设；普通用户只能删除自己创建的预设：
```
nai预设删除 预设名
```

删除预设不会删除已经生成的图片，也不会影响其他预设，只是之后不能再通过该名称引用它。

### 预设的引用和优先级

基础命令 `nai` 会直接读取预设内容，不调用 AI：
```
nai
s1=画质
s2=白发少女
```

`nai画图` 会在高级参数 LLM 使用 `ds` 后再使用预设内容：
```
nai画图
s1=白发少女
s2=画质
ds=坐在窗边看书
```

如果预设或命令中写了显式参数，最终会覆盖 LLM 生成的同名参数。预设中的普通文字按正向 `tag` 处理；如果希望 `ds` 作为主要描述，不要在预设中写普通提示词或 `tag=`，可改用 `a_tag=` 等包装参数，或将风格内容直接写入 `ds`。

如果希望用户不填写 `s1` 时自动使用预设，请将 `defaults.default_preset` 设置为预设名称。这和 `llm.default_prompt` 不同，后者只是 AI 模式没有预设且 LLM 未生成正向提示词时的兜底提示词。
